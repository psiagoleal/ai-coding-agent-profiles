# MT-12 — UI React, se a empresa fechar React

**Contexto.** O padrão da empresa provavelmente será web; falta saber se o front será React ou Svelte. A skill de SvelteKit já cobre o segundo caso.

**Escopo**

- Só começar depois da decisão da empresa.
- Gate de detecção lendo `package.json`.
- Consumir o contrato de `criar-servico-fastapi`, com a mesma regra de token no servidor.

**Critério de aceite.** Decisão registrada; se for React, a skill entrega gate, estrutura e template equivalentes aos da de SvelteKit.

**Fora de escopo.** O que não estiver acima. Mudança de escopo vira ticket novo, não
crescimento deste.
