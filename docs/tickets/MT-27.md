# MT-27 — Enumerar skills sem `node_modules`, com teste

**Contexto.** Observado em uso real (2026-10-04): o Playwright **embarca** arquivos `SKILL.md`,
e uma skill com `node_modules` dentro injetou duas skills de terceiros no inventário de um
projeto. No nosso instalador, `dirs_com_skill()` (`scripts/setup-profile.sh`, linha 116)
enumera `SKILL.md` sem excluir `node_modules`, enquanto a linha 835 do mesmo arquivo exclui.
Hoje só o `-maxdepth 3` nos protege — proteção por acidente.

**Escopo**

- Excluir `node_modules`, `.venv`, `__pycache__`, `dist`, `build` e `target` na enumeração.
- Mesma exclusão onde mais se varre `SKILL.md`.

**Critério de aceite.** Com um `SKILL.md` plantado dentro de `node_modules` de uma skill, a
listagem não o inclui, e o teste de regressão cobre o caso.

**Fora de escopo.** Política sobre skill de terceiro que o projeto queira de propósito.
