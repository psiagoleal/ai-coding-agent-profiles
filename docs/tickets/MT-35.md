# MT-35 — Roteamento validado das skills de delegação

**Contexto.** Seis skills tratam de delegação, cada uma num eixo diferente: por que (dado
sensível), como (endpoint), quando (cota), quantos (fan-out), para quê (crítica independente) e
despacho. O autor do framework não lembrava quantas eram, e o agente que roda dentro dele não
achou a que importava. Eixo é fronteira de seleção útil — o problema não é consolidar, é
roteirizar.

**Escopo**

- Tabela "Preciso de → Ler" cobrindo os seis eixos, no arquivo de regra e no índice de skills.
- Fronteira negativa recíproca nas seis descrições.
- Validador: toda linha da tabela aponta para skill existente, e toda skill de delegação
  aparece na tabela.

**Critério de aceite.** O validador sai zero sem linha órfã e sem skill de delegação ausente, e
entra no CI. Tabela sem validador apodrece, por isso o validador é parte do aceite.

**Fora de escopo.** Fundir skills. Ver MT-37 para a redundância real.
