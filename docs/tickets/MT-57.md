# MT-57 — O instalador reprova skill sem `invocacao` ou com valor inválido

**Contexto.** A spec 0001 decidiu que a ausência do campo é erro de instalação, porque cair
num padrão esconde a decisão. Nada no `setup-profile.sh` lê o campo hoje.

**Escopo**

- O instalador lê `invocacao` de cada skill selecionada, de todas as fontes, antes de criar
  qualquer adaptador.
- Ausente: reprova, nomeando o arquivo. Fora de `{humano, modelo}`: reprova, nomeando o
  arquivo e o valor.
- Reprova antes de escrever no alvo: instalação parcial é pior que nenhuma.

**Critério de aceite.** Critérios 4 e 5 da spec 0001, como asserções no
`testar-instalador.sh`, com skills fabricadas. A regressão inteira do instalador continua
passando.

**Spec.** [0001](../specs/0001-invocacao-declarada.md)

**Depende de.** MT-56. Sem o campo em todas as skills, esta reprovação quebraria toda
instalação existente.
