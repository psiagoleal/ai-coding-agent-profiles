# MT-20 — Skill de decisão tipada como camada de roteamento

**Contexto.** Surgiu uma classe de modelo que devolve decisão tipada com probabilidade
calibrada em vez de texto, útil para escolher a qual modelo delegar cada tarefa. O plano e a
verificação das alternativas estão em [`docs/planos/decisao-tipada.md`](../planos/decisao-tipada.md).
Trabalho coordenado com o `agentry`, que fica com o runtime.

**Escopo**

- Skill `decisao-tipada`, neutra em relação a fornecedor: quando a decisão tipada bate uma
  chamada de chat, contrato de entrada e saída, regra de escalada por limiar de confiança.
- Guardas por perfil: licença não-comercial bloqueia perfil `empresa`; pesos locais são
  egresso `local-only`; API hospedada segue as regras de nuvem já existentes.
- Protocolo de medição: gabarito a partir de tarefas reais, acerto **contra o baseline
  trivial**, calibração e custo ponta a ponta com o roteador incluído.

**Critério de aceite.** A skill só é escrita depois de existir medição: um gabarito real, o
número do baseline trivial e o do roteador candidato. Sem isso, o ticket fica em aberto.

**Dependência.** Passos 1 a 4 do plano são do `agentry` (contrato, telemetria, baseline,
primeiro provedor).

**Fora de escopo.** Implementar provedor no runtime — isso é do `agentry`. E adotar qualquer
roteador sem medição.
