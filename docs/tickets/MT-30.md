# MT-30 — Pin de procedência para fonte externa de skills

**Contexto.** A ADR 0015 abriu múltiplas fontes (`fontes_extras`) sem versão nem hash.
Observado em uso real (2026-10-01): um projeto resolveu isso com um arquivo de origem que
registra o commit do acervo de onde as skills vieram, a data e as áreas trazidas, gerado por
script e marcado "não editar". Sem pin, atualizar fonte externa é confiança cega.

**Escopo**

- Arquivo de procedência gerado na instalação: fonte, commit, data, conjunto trazido.
- Verificador que confere se o conteúdo instalado corresponde ao pin.
- `--update` recusa quando o pin não casa, em vez de sobrescrever.

**Critério de aceite.** Instalar de uma fonte grava o pin; adulterar um arquivo instalado faz o
verificador reprovar.

**Fora de escopo.** Assinatura criptográfica da fonte.
