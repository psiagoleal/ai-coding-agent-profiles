# MT-32 — Relocar segurança e fluxo: detalhe para a skill, fluxo para tabela

**Contexto.** Mesma medição do MT-31: a seção de segurança tem 39 linhas e a de fluxo ágil 30,
somando 69. A de segurança repete o que a skill `secrets-guard` existe para dizer; a de fluxo
descreve em prosa o que é decisão por situação.

**Escopo**

- Segurança: ficam no arquivo de regra três linhas imperativas (nunca exibir segredo,
  verificação indireta, e o ponteiro); o detalhe vai para dentro da skill.
- Fluxo: vira tabela **gatilho → ação → prova**, uma linha por situação.

**Critério de aceite.** As duas seções somam menos de 20 linhas no arquivo de regra, e cada
item removido aparece no destino, conferido item a item.

**Fora de escopo.** Mudar o conteúdo das regras — só o lugar e a forma.
