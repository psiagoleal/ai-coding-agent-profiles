# MT-36 — ADR do hook que recusa, e resolver a ADR 0009

**Contexto.** A ADR 0009 decide "hooks como sensor e skills como estratégia", está `Proposed`,
e sensor observa. O hook de git entregue em `1be2af1` **recusa**. Estender a 0009 para
significar o oposto corrompe o registro: se for aceita depois, carrega semântica de bloqueio
nunca discutida.

**Escopo**

- Resolver a 0009 primeiro — aceitar ou recusar, com a evidência de uso que ela esperava.
- ADR nova para hook de enforcement: o que pode recusar, por que o padrão é negar, qual o
  escape da pessoa, e por que a garantia é defesa em profundidade e não completa.

**Critério de aceite.** As duas ADRs existem sem se contradizer, e a nova registra o limite
declarado em vez de prometer garantia.

**Fora de escopo.** Implementação, que é o MT-24.
