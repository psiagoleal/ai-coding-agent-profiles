# MT-17 — Skill `exercitar-skill`: derivar as racionalizações de observação

**Contexto.** As tabelas 'o que você vai pensar para pular a regra' são escritas por intuição. Dá para derivá-las de teste: rodar o cenário sem a skill e capturar a desculpa real do agente.

**Escopo**

- Cenário de pressão com três ou mais restrições simultâneas, exigindo escolha concreta.
- Execução **sem** a skill, para capturar a racionalização observada.
- Cada desculpa observada vira uma linha na tabela da skill; reexecução com a skill precisa mudar o comportamento.

**Critério de aceite.** Uma skill existente passa pelo ciclo e ganha pelo menos uma linha de tabela que não estava lá antes, derivada de execução.

**Nome.** `exercitar-skill` — nomes precisam ser únicos entre todas as fontes instaladas
(ADR 0013), e o nome mais óbvio já existe em outra biblioteca.

**Fora de escopo.** O que não estiver acima. Mudança de escopo vira ticket novo.
