# MT-10 — Skill de CI/CD: pipeline como gate

**Contexto.** Três skills de stack entregues e nenhuma tem gate que roda em servidor. Pipeline que não pode falhar não prova nada.

**Escopo**

- Matriz por stack (Rust, C++, Python, Node) com o comando real de cada uma.
- Segredo por *secret store*, nunca em variável de repositório pública.
- Artefato e release; cache com chave que invalida sozinha.

**Critério de aceite.** Um workflow de exemplo por stack, e a regra de que o gate do CI é o mesmo comando do `AGENTS.md`.

**Fora de escopo.** O que não estiver acima. Mudança de escopo vira ticket novo, não
crescimento deste.
