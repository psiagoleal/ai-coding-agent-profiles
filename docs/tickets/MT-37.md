# MT-37 — Resolver a sobreposição entre as duas skills de fan-out

**Contexto.** `paralelizacao-em-grafo` (152 linhas) e uma skill de despacho de subagentes (57
linhas, em biblioteca separada) decidem a mesma coisa: quando paralelizar versus sequenciar.
Diferente dos seis eixos de delegação, que se dividem por decisão, esta é redundância de
verdade: duas respostas para uma pergunta, e o disparo por descrição pode pegar a mais fraca.

**Escopo**

- Comparar as duas e decidir: fusão, ou fronteira explícita entre elas.
- Se fundir, o conteúdo específico vai para ilha de usuário ou para a skill que sobrar.
- Fronteira negativa nas duas, se sobreviverem as duas.

**Critério de aceite.** Uma pergunta, uma skill: a busca por "quando paralelizar" leva a um
único lugar, e o lint de fronteira (MT-29) passa nas sobreviventes.

**Fora de escopo.** Criar subagentes. É a rodada de análise seguinte que decide isso.
